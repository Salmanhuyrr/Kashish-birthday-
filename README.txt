# Happy Birthday Kashish ❤️

## GitHub Pages setup

1. Create a GitHub repository.
2. Upload:
   - `index.html`
   - `style.css`
   - `script.js`
   - the `assets` folder
3. Put the girl's photos inside `assets` and name them:
   - `memory1.jpg`
   - `memory2.jpg`
   - `memory3.jpg`
4. In GitHub: **Settings → Pages → Deploy from branch → main → / (root)**.
5. Open the generated GitHub Pages link.

### To add more memories
Copy one `.memory-card` block in `index.html`, change the image name and caption.

### Important
The website uses Google Fonts (`Cormorant Garamond`, `Great Vibes`, `Montserrat`) for a close match to the screenshots. GitHub Pages needs internet access for those fonts. If you want it fully offline, download the fonts and place them in `assets/fonts`.
